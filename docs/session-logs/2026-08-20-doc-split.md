## 关键决策与发现

1. **共享构件不拆**：表格、代码块、mermaid 图、图片在两份文档中保持同一内容（图内中文标签 / 代码中文注释原样保留）——强行翻译构件内容收益低、漂移风险高；只有成对的散文段落与标题按语言分流。
2. **8.2 / 10.4 混排 bullet 按 `。/ ` 边界拆分**：`- **中文标签 English label**：中文正文。/ English body` 拆为两条语言各自的 bullet，双语标签按 CJK/ASCII 词元切分为各自的纯语言标签。
3. **原文缺陷修复**：原文 §4.4 的「为什么不用 process / microvm / lightvm 三分类」段落在原文档里中英两份内容完全相同（英文版从未翻译，均为中文）——拆分时为英文版补译。
4. **命名约定**：英文版保留原文件名（README.md / agent-runtime-architecture.md，GitHub 与外部链接不断链），中文版加 `.zh-CN.md` 后缀；此约定写入 AGENTS.md §5.5。
5. **ADR 不拆**：ADR 是只增不删的历史决策记录，AGENTS.md §5.2 已明文「中英对照段落」为其风格；拆分只适用于面向外部读者的顶层文档。
