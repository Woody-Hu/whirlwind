## 关键决策与发现

- AGENTS.md 定位为操作层规范，明确"冲突时以 ADR 为最高事实源"，避免与架构文档/ADR 形成三个事实源。
- 抽象接口速查表以"新增 X = 新增一个实现文件、核心零改动"为开闭原则的可验证判据；若接入新能力需改既有接口签名，先修订 ADR。
- benchmark 验收基线整理自 ADR/README/测试文件：冷启动 p50 ≤ 250ms、WAL 组提交 ≥ 5k/s、bus 扇出 ≥ 20k/s、时间轮 10k schedules、warm 池认领 p50 ≤ 2ms。

- 发现项目文档为中英双语惯例；AGENTS.md 面向协作者用中文为主，关键术语保留英文。
